A short rant for the Angry Judge contest: a shopper comes in for milk, gets flagged by the self-checkout machine as a shoplifter over his own bananas, and has to wait for an employee to confirm he is allowed to buy them. The entry is 397 characters, runs with no dependencies, and lives entirely in `main.py`.

## Run it

```sh
python3 main.py
```

This prints the entry and writes it to `/output/entry.txt`.
